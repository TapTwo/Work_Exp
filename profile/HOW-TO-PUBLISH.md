# Publishing the profile README

GitHub shows a README on your profile page when it lives in a repo named exactly after your
username (`TapTwo/TapTwo`), at the repo root, and is public.

1. github.com → **New repository** → name: `TapTwo` → Public → "Add a README" → Create.
2. Replace the generated README.md with `profile/README.md` from this folder.
3. Commit. The content appears at https://github.com/TapTwo immediately.
